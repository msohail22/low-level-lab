## Description

Given the head of a singly linked list, reverse it in place and return the new head.

In place means you must not allocate new nodes. You may only change the `next`
pointer of the nodes you already have. Use `O(n)` time and `O(1)` extra space.

```cpp
struct Node {
  int value;
  Node* next;
};
```

## Input

Line 1 — an integer `n`, the number of nodes, where `0 <= n <= 10^6`.

Line 2 — `n` integers separated by spaces, the values in list order. Each value
fits in a 32-bit signed integer. This line is empty when `n` is 0.

## Output

One line with the `n` values in reversed order, separated by single spaces. Print an
empty line when `n` is 0.

```text
5
1 2 3 4 5
```

```text
5 4 3 2 1
```

<Answer>

```cpp
Node* reverse(Node* head) {
  Node* prev = nullptr;
  Node* curr = head;

  while (curr != nullptr) {
    Node* next = curr->next;  // save it before we destroy the link
    curr->next = prev;        // point backwards
    prev = curr;              // walk both pointers forward
    curr = next;
  }

  return prev;  // curr is null here, so prev is the last node we saw
}
```

Walk the list once and flip one arrow per step. `prev` is the part already
reversed, `curr` is the node being flipped, and `next` exists only because
writing `curr->next = prev` destroys the only reference to the rest of the list.

```
start      prev=null   curr=1 -> 2 -> 3 -> null
step 1     null <- 1        curr=2 -> 3 -> null
step 2     null <- 1 <- 2        curr=3 -> null
step 3     null <- 1 <- 2 <- 3        curr=null
return prev = 3
```

Starting `prev` at `nullptr` is what turns the old head into the new tail.

</Answer>
