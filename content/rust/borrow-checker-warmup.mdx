## Problem

This program does not compile. Fix it without changing what it prints, and without
using `clone()`.

```rust
fn main() {
    let mut words = vec![String::from("alpha"), String::from("beta")];

    let first = &words[0];
    words.push(String::from("gamma"));

    println!("{}", first);
}
```

Expected output:

```text
alpha
```

## Constraints

- No `clone()`, no `unsafe`, no `Rc` or `RefCell`.
- `words` must still end up with three elements.

## Example

```text
(no input)
```


<Solution language="rust">

```rust
fn main() {
    let mut words = vec![String::from("alpha"), String::from("beta")];

    // The borrow starts and ends here, before the mutation.
    println!("{}", &words[0]);

    words.push(String::from("gamma"));
}
```

</Solution>

## Explanation

`&words[0]` is an immutable borrow of the vector. `words.push(...)` needs a mutable
borrow. Rust's rule is that you may have many readers or one writer, never both at
once. The original code holds a reader (`first`) across the write (`push`), so it is
rejected.

The reason this rule exists is not style. `push` may run out of capacity, allocate a
bigger buffer, move every element into it, and free the old one. If `first` were
still alive it would now point at freed memory.

```
before push        heap: [ "alpha" ][ "beta" ]  cap 2
                         ^
                     first

push needs cap 3 -> allocate a new buffer

after push         heap: [ "alpha" ][ "beta" ][ "gamma" ]  cap 4
                   old buffer: FREED
                         ^
                     first  ... dangling
```

So the fix is to make the borrow not overlap the mutation. Reading the value and
printing it in one statement ends the borrow at the end of that statement, which is
before `push` begins.

Everyday comparison: you cannot read a page of a book while someone else is
re-binding it into a bigger cover. Read the page, put it down, then let them rebind.

In C++ the same code compiles and gives you a use-after-free that may look fine in
testing. That is the whole difference the borrow checker buys you.
