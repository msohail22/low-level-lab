# Learning Platform Feature Roadmap

**Date:** 2026-08-16  
**Status:** Phase 1 in progress; later phases deferred

## Phase 1 — High impact (building now)

1. Learning paths / tracks + progress %  
2. Spaced repetition (due queue from wrong/aging attempts)  
3. Streaks + daily goal  
4. Bookmarks + review-my-mistakes  
5. Richer explanations (`whyWrong`, related question link; diagrams later)

## Phase 2 — Engagement (later)

6. Daily challenge + day leaderboard  
7. Achievements / badges  
8. Moderated question discussion  
9. Follow authors / curated playlists  

## Phase 3 — Pedagogy (later)

10. Progressive hints  
11. Adaptive next-question suggestions  
12. Code sandbox  
13. Glossary / concept cards  

## Phase 4 — Trust & quality (later)

14. Report question → review queue  
15. Question version history  
16. Author reputation  

Infra already in `docs/to-do-later.md`: Redis question cache, realtime DO leaderboard, GraphQL, OpenFGA prod, pruning.
